# 심플리홈 구독 자료

심플리홈 인스타그램(@__simplyhome)의 게시물 750개를 한 화면에서 볼 수 있는 앱입니다.
오콘목달 대시보드의 '구독' 탭에서 심플리홈 부분만 그대로 옮겨 왔습니다.

- 모은 날: 2026-09-26
- 글 범위: 2022-11-24 ~ 2026-09

## 화면 켜는 법

컴퓨터에 [Node.js](https://nodejs.org) 20 이상이 있어야 합니다.

```
npm install
npm run dev
```

그다음 브라우저에서 http://localhost:3000 을 엽니다.

화면에서 할 수 있는 일은 다음과 같습니다.

- 위쪽 칩으로 분류(공구 오픈·마감, 정리·비움 등)를 골라 봅니다.
- "꼭 봐 (벤치마킹)"를 누르면 벤치마킹 메모가 붙은 글만 봅니다.
- "반응이 튄 글"을 누르면 평소보다 조회·좋아요·댓글이 크게 나온 글만 봅니다.
- 최신순, 인기순, 조회수순으로 정렬합니다.
- 카드를 누르면 캡션, 대본, 지표, 댓글 원문, 벤치마킹 메모를 한 번에 봅니다.

## 인터넷에 올리고 싶을 때

이 폴더를 GitHub 저장소 그대로 [Vercel](https://vercel.com)에 연결하면 따로 설정할 것이 없습니다.
댓글 원문에는 다른 사람의 인스타그램 아이디가 들어 있습니다. 그래서 주소를 아무에게나 공개하지 않는 편이 좋습니다.

## 원래 대시보드와 다른 점

- 새 글을 가져오는 "동기화" 버튼을 뺐습니다. 새 글을 가져오려면 인스타그램 수집 도구(Apify) 계정과 키가 필요하기 때문입니다.
- 대본을 새로 만드는 버튼과 글 삭제 버튼을 뺐습니다. 이 앱은 자료를 보는 용도입니다.
- 글을 열면 인스타그램에 올라간 실제 사진을 같이 보여 줍니다.
